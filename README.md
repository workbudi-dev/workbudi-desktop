# WorkBudi for Windows and Mac

Download the latest version:

**[Download WorkBudi for Windows](https://github.com/workbudi-dev/workbudi-desktop/releases/latest/download/WorkBudi-Setup.exe)**

**[Download WorkBudi for Mac](https://github.com/workbudi-dev/workbudi-desktop/releases/latest/download/WorkBudi-Mac.dmg)**

Every new feature on the web app shows up in the desktop app right away.

## WorkBudi for Windows

Windows 10 and 11 (64-bit).

1. Open `WorkBudi-Setup.exe`.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
3. Sign in with Google, Microsoft, Slack or your email.

The Windows app updates itself: new versions download in the background and install the next time WorkBudi restarts.

## WorkBudi for Mac

Test version. Works on Intel and Apple-chip Macs.

1. Open `WorkBudi-Mac.dmg` and drag **WorkBudi** into **Applications**.
2. Open WorkBudi. The first time, macOS says it can't check the app: click **Done**.
3. Open **System Settings** > **Privacy & Security**, scroll down and click **Open Anyway**, then enter your password. You only do this once.
4. Sign in with Google, Microsoft, Slack or your email.

New Mac versions are downloaded from this page for now.

This page only hosts the installers. Learn more at [workbudi.com](https://workbudi.com).
